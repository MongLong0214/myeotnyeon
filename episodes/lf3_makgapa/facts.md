## 발언 보존 — 축어·화자·전달 경로

법정 협박은 행위의 요지만 간접 서술한다. B·C의 문구를 A에게 붙이거나 서로 다른 기사를 합쳐 새 대사를 만들지 않는다. 범행 중 피해자의 발언과 마지막 말은 사용하지 않는다.

## 충돌·보류·제외 기록

- 범행 시각 자정/오전 2시, 금품 900만원/1200만원, 결성 월 9월/10월이 충돌한다. 날짜와 금액의 정밀도를 임의로 높이지 않는다.
- YTN 회고는 10월29일을 사건 발생과 연결하지만 당대 두 매체는 10월5일 범행으로 일치한다. YTN을 범행일 근거로 사용하지 않는다.
- 한국일보의 무기징역 3명 표현은 서울신문의 무기형 2명·별도 유기형 1명과 다르다. A의 확정판결만 결말에 사용한다.
- 1996년 성인 피해자 강도살인만 다룬다. 2003년 출소 조직원의 별건 성범죄, 지존파의 성범죄, 나이 미확인 추가 강도 피해는 편입하지 않는다.
- 생매장이라는 확정 보도 내용은 말로만 전달한다. 나체·결박·삽질·매장·유해 발굴·고통 소리는 사용하지 않는다.

## 레드라인·보관 메모

- 본편의 직접 피해자는 성인이다. 성범죄·미성년 직접 피해 사건, 범행 중 대사·내면 독백·미확인 동기·피해자 책임 추정은 사용하지 않는다.
- 실명은 출처 원문에만 남긴다. 제작 호명은 위 역할명으로 통일한다. 실제 외모·정확한 주거·신원 재현은 하지 않는다.
- 원문 수집은 공개 페이지 직접 HTTP만 사용했다. 유료 서비스·Exa·네이버 API·네이버 키·생성형 이미지·음성 호출은 사용하지 않았다.
- `raw/manifest.json`은 채택/검토 상태와 보관 파일 해시를, `raw/SHA256SUMS`는 바이트 기준 검산용 해시를 담는다. 검색 결과 요약은 채택 근거로 세지 않았다.
