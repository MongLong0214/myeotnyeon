`ffprobe -count_frames`로 영상 해상도·프레임 수·길이를 확인했다. FFmpeg로 최종 H.264의 모든 프레임을 384×216 회색조로 디코딩한 뒤 인접 프레임의 절대 차이 평균(MAE)을 구했다. 컷 경계의 큰 변화는 움직임 판정에서 제외했다. 카메라 이동과 별개로 입·눈·머리·팔·몸통·걷기 리그의 변화도 컷별 두 시점 렌더에서 확인했다. 캐릭터 수치는 컷별 캐스트를 실제 콘택트 시트와 대조했다. C15만 빈 주차장·수레·수송차이며, 이 컷도 카메라가 연속 이동한다.

AAC 스트림과 MP4 컨테이너 길이는 인코더 패딩을 포함하여 45.013초다. 영상 트랙은 정확히 45.000초이며 내레이션 원본 추출 길이도 45.000초다.

## 음성·자막

- `audio/voice_first90.wav`의 첫 45초와 `public/narration_45s.wav`의 PCM 바이트가 **완전히 같다**. 속도·문장·사실·목소리를 바꾸지 않았다.
- PCM은 48kHz / 모노 / 24bit. 프레임별 1,600샘플의 RMS 1,350개로 진행자 입을 구동한다. 픽셀 입 모양은 음소 인식이 아닌 음량 기반 립플랩이다.
- 최종 MP4에서 디코딩한 오디오의 프레임별 RMS와 원본 RMS의 상관계수는 **0.999993694**다. 지연 없이 같은 0초를 기준으로 비교했다.
- `shots_v1.json`의 기존 자막 시간을 30fps로 반올림했다. 긴 문장은 단어 경계에서 두 줄로만 나눴다. 45초 경계에서 마지막 자막은 ‘십월 십오 일 자정 무렵’으로 제한했다. N007의 나머지 문장은 후속 분량에 해당한다.
- 실제 영상에서 자막 외 글자 레이어는 없다. 시계는 숫자 없는 바늘·눈금이며, 자료 보드·돈가방·차량·법정에는 식별 텍스트가 없다. 스타일 시트와 콘택트 시트의 제작용 라벨은 영상에 들어가지 않는다.
- 46px 글자에서 모든 문자를 1em으로 잡은 보수적 최대 줄 폭은 **1,334px**, 외곽선 포함 안전 범위는 x=**289–1,631px**다. 이 값은 실제 폰트 폭 실측이 아니라 상한 추정이다. 글꼴 로딩·두 줄 자막·화면 안 배치는 최종 프레임에서 직접 확인했다.

## 금지선과 사실

- 피·상처·피격·사망·쓰러짐·차량 충돌 장면: **0회**. 총 발사 동작·총성·비명·섬광도 없다.
- 총격 내레이션은 차와 진행자 화면 위에서 이어지고, 사망 내레이션은 빈 주차장으로 넘어간다. 살아 있는 직원이 쓰러지거나 사라지는 동작을 만들지 않았다.
- 직원 얼굴 특징·실명·이름표: **0개**. 직원 3명은 같은 무안면 리그이며 신체·행동도 일반적인 재구성이다. 두 강도는 피부·눈·입이 보이지 않는 가상 후드/비니 실루엣이다.
- 진행자·형사·판사는 가상 채널 캐릭터다. 실제 피고인·피해자·수사관·법관의 외모를 참조하지 않았다. 특정 TV 애니메이션의 캐릭터·고유색·포털·상표 요소는 없다.
- 사건 사실은 제공된 `facts.md`의 기존 채택 행과 대본만 사용했다. 관계자 3명, 가방 2개·각 3억원, 가져간 가방 1개, CCTV 없음, 인근 지하주차장에서 차량 변경, 두 사람의 무기징역을 유지했다. 사망자 연령은 기존 대본의 ‘사십 대’ 그대로다. 새 법률·사건 주장은 추가하지 않았다.
- Blender·3D·유료 AI·새 패키지 설치·외부 네트워크·업로드: **사용 없음**. Remotion 내부 루프백 서버만 사용했다. 새 소스·자산·번들·검수·임시 파일은 요청한 두 cartoon 경로 아래에 생성했으며 기존 파일을 덮어쓰지 않았다.

## 검사와 남은 작업

최종 v3 진입점과 관련 TSX는 TypeScript strict/noEmit 검사를 통과했다. React 점검에서는 프레임 기반 상태 계산, 훅 사용 위치, 안정적인 SVG 키, 외부 요청 없는 자산 경로를 확인했다. 렌더 측정 원자료는 `qa/render_measurements.json`, 다시 측정하는 스크립트는 `production/compositor/src/cartoon/check_pilot_v3.py`다. 기존 출력이 있으면 덮어쓰지 않으므로 별도 실행 시 새 출력 이름이 필요하다.

요청한 45초 파일럿·스타일 바이블·PNG 시트·콘택트 시트·수치 검수는 완료했다. 미완료 항목은 없다. 45초 이후 본편은 이번 작업 범위에 포함되지 않는다.
