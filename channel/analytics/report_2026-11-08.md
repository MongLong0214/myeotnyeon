# 몇년나옴 Shorts 성과 분석 — 2026-11-08

공개 Shorts 13편(조회 16,354회)을 YouTube Analytics API와 Data API로 읽기 전용 조회해 분석했다. 하위 에이전트의 파일 쓰기가 막혀서 CTO가 저장했다. 표본이 13편이고 주제·길이·공개일이 함께 바뀌었으므로 결과는 상관이지 인과가 아니다. Analytics 집계는 11-05까지다. 같은 표는 매주 `weekly_report.py --pull`로 다시 만든다.

부가 정보:
- 유입: Shorts 피드 95.3%, 검색 2.7%. 검색어 1·2위는 "야차"와 "야차룰"(q014).
- 시청자: 남성 84.5%, 남성 25–54세 67%, 모바일 90%.
- 지금 전환율로 구독 1,000명에 닿으려면 약 270만 조회가 필요하다.

## 가설 재점검
- **H1 (첫 2초):** 판정 가능. 실제 병목은 넘김이다. 실행 1로 11-22까지 판정한다.
- **H2 (코미디):** 몰입은 중상위, 엔딩은 최약이다.
- **H3:** 유지.
- **H4 (제목):** 피드에서는 판정할 수 없다. 검색 효과만 실행 4로 본다.
- **H5 (길이):** 비율 상승은 기계적 효과다.
- **H6 (주제):** 13편으로는 판정할 수 없다.

## 업계 통설 vs 우리 데이터
"viewed 70% 이상이면 확장", "평균 시청 100% 이상이 좋다", "댓글은 조회의 1%" 같은 수치는 출처가 없어서 판정 기준으로 쓰지 않았다. 위 숫자는 모두 API 원자료에서 계산했다. 원자료는 `daily/api_2026-11-08.json`, `daily/extra_2026-11-08.json`, `retention/*.json`에 있다.
