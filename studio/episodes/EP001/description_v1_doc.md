# EP001 공개용 문안 (초안 · 공개 승인 전)

## 제목 후보

1. 음주운전 신고하겠다며 막아선 사람을 차로… 법원은 왜 집행유예를 택했나 (권장)
2. 반성 없다면서 집행유예? 대구 주차장 특수상해 판결, 판결의 이유
3. '두려운 마음 참작'은 무슨 뜻이었나 — 판결문이 따진 것들

제목은 확인된 행동(신고하겠다며 막아선 사람을 차로 침)과 실제 결론(집행유예)만 담았습니다. "역대급", "살인미수" 같은 표현은 쓰지 않습니다.

## 썸네일

`thumbnail.png` — 차 앞을 막아선 인물과 전조등, 문구 "반성 없다면서 집행유예?"와 "판결문이 따진 것은 따로 있었다". 실제 얼굴·피·폭력 장면 없음.

## 설명란

2022년 7월 28일 새벽, 대구의 한 주차장. 음주운전으로 신고하겠다며 차 앞을 막아선 사람을 운전자가 차로 여러 차례 밀어 넘어뜨렸습니다. 1심 법원은 운전자가 진지하게 반성한다고 볼 수 없다고 하면서도 징역 8개월에 집행유예 2년, 사회봉사 120시간을 선고했습니다. 이 영상은 그 판결이 무엇을 인정했고, 형을 어떻게 정했는지를 따라갑니다.
