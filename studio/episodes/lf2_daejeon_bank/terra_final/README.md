# LF2 핵심 동작 시안 (CEO 검수용)

- 640×360, 12초 proof만 갱신했다. 1080p 및 전편 렌더는 하지 않았다.
- 음성은 기존 `audio/mix_first90_polished.wav`의 0–12초 그대로다. 원본 cue(`_work/full4/subtitles.ass`)의 세 문장 범위는 0.00–2.23, 2.42–5.41, 5.42–7.81초다.
- S01은 차량 차단 관계, S02는 가방을 내리는 운송관계자와 뒤/옆에 나타난 두 복면인, S03은 익명 복면인의 손·팔에 연결된 권총 발사만 보인다. 피격·상처·발사자 신원은 묘사하지 않는다.
- `proof_extract_*_start|mid|end.png`은 각 실제 발화의 시작·중간·끝에서 MP4를 디코드한 프레임이다. S03은 마지막 발화 뒤에도 같은 장면을 유지한다.
