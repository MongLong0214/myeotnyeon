# DECISIONS — 판결의 이유 EP001

작성 2026-10-25. 인수인계서 v1.3(최신 지시 우선) + 제작 중 사용자 추가 지시를 반영한 결정과 이유.

## 사건 선정과 서사
- **사건**: 사용자가 지정한 이미지의 판결 = 대구지방법원 2023고단202 (특수상해, 2023. 8. 16. 선고). 사건번호·선고일은 로이슈 보도(판결 인용)에서 확인.
- **모드 VERDICT_OPEN**: 결과(집행유예)가 커뮤니티로 이미 널리 퍼져 있어, 콜드오픈에서 결론을 밝히고 "왜"를 약속. 05:30(Q29)에서 주문을 정식 공개.
- **중심 쟁점 1개**: "반성하지 않는다고 본 피고인에게 왜 형의 집행을 미뤘나". 유죄 판단(고의·상해·인과관계)은 그 전제로 ACT G–H에서 다룸.
- **판결문 원문 미확보**: 대법원 판결서 인터넷 열람은 유료(건당 결제)라 별도 승인 없이 진행하지 않음. 판결 인용 보도(로이슈·로톡뉴스)로 재구성하고 화면·설명란에 명시. 공개 전 원문 확보를 권장 (HOLD 사유).
- **익명화**: A씨·B씨 유지. 판사 실명은 공개 보도에 있으나 인물 공격으로 번질 위험 때문에 영상에서 쓰지 않음. 성별은 법적 쟁점과 무관하고 커뮤니티 성별 갈등을 키울 수 있어 내레이션에서 쓰지 않음.
- **커뮤니티 왜곡 교정**: 음주운전 기소(보도 없음)·체포(보도 없음)·"무서워서 봐줬다"(실제로는 범행 동기에 관한 유리한 정상 3개 중 하나)를 Q16·Q34·Q36에서 사실대로 정리. 익명 댓글의 "항소기각" 주장은 근거가 없어 사용하지 않음.
- **통계 사용**: 2023년 1심 특수상해(양형기준 적용) 74.9% 집행유예를 맥락으로 제시하되, 판결을 옹호하거나 비판하는 근거로 쓰지 않음.
- **감경 해설**: 8개월이 법정형 하한(1년)보다 낮다는 점에서 감경 적용으로 "볼 수 있다"고만 말하고, 보도에 조문이 없다는 점을 화면에 표기 (제작진 해설 라벨).

## 화면
- **1차 방향 (폐기)**: 기본 도형 마네킹·상자형 차량의 비실사 3D. 사용자가 "블렌더 사용 수준이 너무 낮다", "실사영화 수준의 모델링을 원한다"고 지시 → 전면 교체.
- **2차 방향 (채택)**: 환경·차량·소품은 실사 수준(CC0 PBR 재질·스캔 모델·실차 모델), 인물은 해부학적 인체에 얼굴 없는 마네킹 머리와 단색 석고 재질. 이유: 인수인계서가 금지한 "실제 촬영처럼 보이는 실존 인물 재현"을 피하면서 사용자의 화질 요구를 충족. REF01(fern)도 실사풍 환경 + 얼굴 없는 마네킹 조합.
- **얼굴 평탄화 시도 (폐기)**: 스무딩으로 얼굴을 지우는 방식은 머리 형태가 일그러지고 구멍이 생겨 섬뜩함 → 목 위를 가리고 달걀형 마네킹 머리로 교체.
- **색**: 두 인물 모두 중립 회색 계열. 레퍼런스의 인물별 선악 색 대응(빨강/파랑)은 채택하지 않음.
- **폭력 묘사**: 접촉·넘어지는 순간은 "행위 묘사 생략" 카드로 가리고 전후 상태만 표시 (Q10·Q12).
- **브랜드**: 주연 차량(혼다 어코드 모델)의 엠블럼·트렁크 문자·번호판을 제거하고 무표시 판으로 대체. 실제 사건 차량(보도상 BMW)을 재현하지 않음 — 화면은 "승용차"로만 표현. 주차 차량은 번호판·앞뒤 중앙 엠블럼 제거, 중국어 차명 문자가 있는 실피 모델은 제외.
- **차량 탈엠블럼 방식 변경 (근접 점검 결과)**: 중앙 띠 안의 면을 지우던 방식은 그릴·트렁크에 구멍을 냈고, 칠만 바꾸는 방식은 로고가 양각으로 그대로 읽혔음 → 앞뒤 중앙의 작은 독립 조각(엠블럼·차명 문자)만 통째로 제거. 번호판 텍스처는 무지 어두운 판으로 칠함. 제거 후에도 구멍·얼룩이 남는 스포티지·옵티마·센트라는 주차 차량에서 제외 (말리부·CX-5·ES 세 모델만 사용).
- **법정 재구성**: 판사석이 너무 높아(대 위 1.24 m) 의자가 가려져 "나무 벽"으로만 보였음 → 책상면을 대 위 0.78 m로 낮춰 높은 등받이가 보이게 하고, 판사석 의자·변호인석 의자는 기성 모델(Sketchfab CC-BY)로 교체, 모니터·구즈넥 마이크·서류철을 책상마다 배치, 바닥은 Poly Haven 카펫(CC0). 원경 컷은 방청석 뒤에서 방 전체가 보이도록 다시 잡음. 판사·국가 상징물은 넣지 않음.
- **실사 자료 0개**: 레퍼런스가 쓴 뉴스 화면·사진은 모두 자체 조판 카드로 대체. 판결문 스캔·CCTV 화면·진료기록 문서를 흉내 내지 않음 (CCTV는 장치만, 진료기록은 닫힌 서류철 소품만).

## 기술
- **렌더러**: Blender 5.2.3 LTS EEVEE (헤드리스, `--factory-startup --python-exit-code 1`), 합성은 Remotion 4.0.538, 인코딩 ffmpeg.
- **렌더 시간 최적화** (계측 기반): 수목 LOD1/LOD2, 주차 차량 대당 약 14만 면으로 감축, 샘플 20, 그림자 해상도 0.5, 화면 밖 보조광 그림자 끔 → 프레임당 64초 → 약 10–14초.
- **보간**: 느린 카메라 이동 숏은 격 프레임 렌더 후 ffmpeg minterpolate(mci)로 30fps 복원. 인물·차량 동작 숏(Q09–Q12, Q32)은 전 프레임 렌더.
- **정지 판**: 카드가 화면 대부분을 덮는 큐(Q13·Q20·Q21·Q27·Q28·Q33·Q37·Q38)는 렌더된 숏의 한 프레임에 느린 확대를 적용해 추가 렌더를 줄임.
- **인물 자세**: 각도 직접 지정 대신 손·발 목표점 IK. 걷기는 발 디딤 목표를 번갈아 키프레임.
- **TTS**: Supertonic 3 (로컬, OpenRAIL-M 상업 사용 가능, AI 생성 고지 의무). 음성 M2, 속도 0.9. 숫자는 낭독용 한글로 풀어 "3시→삼시" 같은 오독 방지. 전 문장 Whisper 재인식으로 대조(평균 글자 오류율 약 1%).
- **음악·효과음**: 외부 음원 권리 문제를 피하려 numpy로 절차적 합성. 내레이션 구간 자동 덕킹, 마스터 -16 LUFS / 트루피크 -1.5 dBFS.
- **유료 결제·공개 업로드**: 하지 않음 (판결서 열람, 음원 구매, 업로드 모두 미실행).

## 레퍼런스
- REF01·REF02를 각각 원본 그대로 확보(해시 기록). 전 프레임 전환점수·밝기·카메라 이동 수치 처리, 컷 후보 523개 경계 프레임 시각 검수, 전 구간 음성 전사, 음량 측정. 결과는 `references/REFERENCE_ANALYSIS.md`.

## v2 가벼운 편집본 (2026-10-26, 원일 지시)
- **지시**: "정보성 문구·타이포그래피·글자 너무 많으면 안 됨. 다큐가 아니라 가볍게 볼 유튜브 영상. 절대 지루하면 안 됨. 법정씬 너무 많으면 안 됨. 호흡 빠르게." 이어서 "8분이 길면 5분 내외로 줄여도 됨, 억지로 분량 늘리지 마."
- **대체된 규격**: 인수인계서 v1.3의 480초·40큐 고정 격자와 05:30 판결 공개 시점은 이 지시로 대체. 12개 블록(A–L) 순서만 유지. 결과 3분 47초, 판결 공개 2:10(전체의 약 57%). v1 문서형 원고·편집은 `*_v1_doc.*`로 보존.
- **말투·속도**: 해요체 구어, 짧은 문장. 음성 속도 0.9 → 1.2 (초당 약 7.2자, REF02 7.0자와 비슷). 너무 짧은 조각 문장은 합성에서 끝이 잘려 조금 늘림. 음성 인식 대조 평균 글자 오류율 0.6%, 남은 2문장은 인식기가 숫자·발음을 다르게 적은 것.
- **뺀 것**: 수사·기소 절차, 판단 기준 3단계 설명, 지상/지하 표기, 자료 한계 카드 대부분, 법조문 원문 카드. **더한 것(모두 기존 조사 자료 안)**: 커뮤니티 확산 규모(보배드림 원글 조회수), 소문 팩트체크 2개(음주운전 확정? / "무서워했다니 봐줬다"?), 같은 대구지법 비교 사건 1건(신고 후 차를 가로막은 주민을 후진해 친 사건, 징역 8월·집유 2년, 단 전치 2주), 112 신고 요령.
- **비교 사건 서술 교정**: 조사 요약에는 "주차장 입구를 막은 주민을 친 사건"으로 적혀 있었으나 원문 확인 결과 입구를 막은 쪽은 운전자였고, 신고 후 차를 가로막은 주민을 후진해 친 사건 → 원문대로 서술.
- **화면**: 문장마다 컷(평균 약 4초, 그래픽 안에서 키워드가 말하는 순간 추가로 뜸). 그래픽은 1–4단어 큰 글씨: 키워드 팝업, 소문 vs 보도 확인, 법원 저울, 10명 중 7.5명, 형량 숫자선, 8개월 보류 막대, 두 사건 비교, 112. 법정 장면은 죄명·법원의 답·판결 공개에만(전체의 약 10%).
- **소리**: 104 BPM 가벼운 절차적 음악(플럭·킥·셰이커), 판결 직전 0.5초 정적 후 저역 임팩트, 키워드마다 팝·도장 효과음, 컷마다 약한 스위시. 음악은 내레이션보다 약 14 dB 아래. 마스터 -16 LUFS / -1.5 dBTP.
- **인물**: 하나씩 고치는 방식 대신 기성 자산으로 교체 — Quaternius Universal Animation Library 마네킹(CC0, 얼굴 없음) + CMU 모션캡처(무료 사용) 리타깃. 한 손 "멈춰" 동작은 허용 라이선스 안에서 찾지 못해 두 손 정지 동작(CMU) 사용.
