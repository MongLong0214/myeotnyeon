# LF2·N18 실제 재제작 작업 보존 — 미완료

## 요구와 판정
- 요구: LF2 대전 은행강도·N18 훈련병 사건 각각 720초, 지루하지 않은 발화-행동 정합 애니메이션. 반려된 인형·정지그림의 재포장 금지.
- **요구 전체 미완료. 두 720초 납품 MP4는 없음.** 아래는 실제 생성·검증된 중간 산출물이며 납품본이나 품질 PASS가 아니다.

## 실제 생성물
- `lf2/lf2_full_narration.wav`: 새 로컬 한국어 합성 60발화, ffprobe 실측 935.206757초. 12분 아님. 기존 10분 편성예산은 실측 음성이 아니었으며 이번 새 음성은 그 예산보다 길다. 반복 설명을 편집해 줄여야 하며 무음·감속으로 길이를 맞추지 않는다.
- `n18_partial_narration.wav`: 새 로컬 한국어 합성 80발화 원고 중 51발화, 실측 557.417506초. 전체 음성 아님. 해당 발화별 WAV와 원고 전체를 보존했다.
- 음성 엔진: 기존 프로젝트의 로컬 Supertonic 3 M1, 자동 다운로드 금지·offline 합성 실증. Edge 403·macOS 한국어 음성 부재는 더 이상 프로젝트 전체의 TTS blocker가 아니다.
- MP4 네 개: LF2 사건 29.141995초·법정 28.533333초, N18 사건 27.933333초·법정 33.162993초. 모두 새 코드로 그린 960×540 H.264 + AAC 영상이며 기존 반려 PNG·MP4를 영상 입력으로 재사용하지 않았다.
- `artifact_verification.json`: 실제 보존본의 ffprobe duration·stream·SHA256. `render_verification.json`: 원 제작본의 cue별 10/50/90% 실제 MP4 추출 manifest. `representatives_asr.json`: 해당 네 MP4의 실제 음성 인식 결과. ASR은 직접 청취가 아니다.

## 품질 판정
- 사건 동작은 실제로 시간에 따라 다시 그렸다. N18 실제 추출 시트에서 책·군장, 보행/달리기, 팔굽혀펴기·균형 상실의 자막 대응은 확인했다. 이는 연속시청·전체 프레임 PASS가 아니다.
- **법정 연기 FAIL 유지:** 몸통·시선의 의미 있는 변화가 부족하고 팔·서류 위치 변경과 홀드에 치우쳤다. 구형·선고 표기는 개선했으나 사용자가 요구한 애니메이션 연기로 충분하지 않다. 이 실패 문법을 720초 전편으로 확대하지 않는다.
- LF2 총격 발화에 총을 겨누는 그림만 있는 구간, 손-가방 접점·쓰러짐 최종 접지 역시 시간 구간 추가 검토/수정이 필요하다. 사실 횟수·피해자 감정·의료 시술을 창작해 보충하지 않는다.
- 연속 영상·음성 청취는 수행하지 않았다. 지루하지 않음·발화-행동 싱크·청감 품질을 최종 PASS로 주장하지 않는다.

## 동시 작업 충돌과 보존
- 공유 `production/astra_12min/full_narration.json`·`full_synthesis.log`를 별도 실행이 변경한 사실을 발견했다. 로그에는 두 실행의 내용과 NUL 구간이 섞여 전체 작업의 정본으로 쓸 수 없다.
- 이 턴에서 시작한 합성 프로세스 `proc_0a7c965c7aeb`만 중단했다. 다른 실행은 중단·입력·설정변경하지 않았다.
- 중단 당시의 원고 전체를 각 `*_full_narration_cues.json`에서 복원해 `full_narration_source.json`으로 보존했다. 별도 `astra_preserved/`에 당시 WAV·MP4·원고·큐·코드·검증을 복사했다. 이 디렉터리의 보존본은 공유 제작 디렉터리의 후속 변경과 구별해야 한다.
- 해당 시점 보존 manifest는 136파일이다. 이후 추가한 MP3·검증 JSON·이 문서는 그 최초 manifest에 들어 있지 않으며 별도 `artifact_verification.json`에 실제 미디어 해시를 기록했다.

## 남은 실제 작업
1. 단일 작성자/서로 다른 출력 경로를 확정한 뒤 남은 N18 음성을 기존 생성 바이트를 재사용해 마무리.
2. 두 편의 중복 설명을 편집하여 실제 음성에 맞춰 12분을 구성. 시간예산을 음성 실측으로 사칭하지 않음.
3. 법정의 발언권·시선·몸통·손/서류 접점과 사건 장면의 행동을 새롭게 연출하고 대표 장면을 실제 MP4로 재검토.
4. 그 뒤에만 두 전편 렌더·연속 시청/청취·사실/자막/행동 검수. 공개·게시·예약은 수행하지 않았다.
