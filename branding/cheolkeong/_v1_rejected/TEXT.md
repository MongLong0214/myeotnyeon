## 설명
실제 한국 법원 판결을 2D 카툰으로 다시 그리는 숏츠 채널, 철컹철컹입니다.
첫 장면에 판결 결과부터 보여드리고, 무슨 일이 있었는지, 법원은 왜 그렇게 판단했는지까지 짚습니다.
판결·보도를 바탕으로 만든 독창 캐릭터의 2D 애니메이션 재구성입니다. 실제 현장 영상이 아니며 관련자의 신상·외모는 쓰지 않았습니다.

## 디자인
- 강렬한 텍스트형: 검정에서 딥레드로 이어지는 방사형 배경, 노란 굵은 한글에 검은 외곽선, 회색 감옥 창살.
- 배너 안전 영역(1546x423) 안의 텍스트: 「철컹철컹」, 「실제 판결, 결과부터 말합니다」, 「판결 → 사건 → 법원의 반전」. 창살은 안전 영역 밖 장식이다.
- 프로필·워터마크: 창살 위 「철컹」 두 글자만 둔다(98 px·48 px·60 px에서 확인).
- 댓글 유도 문구는 넣지 않았다(채널 주인 지시). 업로드 주기·영상 길이 약속도 넣지 않았다.
