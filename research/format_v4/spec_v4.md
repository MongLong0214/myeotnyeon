## 1. 결론

1. **방향: 듀오톤 재구성 다큐.** 오너 레퍼런스의 공간·빛·카메라·정보 위계를 가져온다. 구성 요소는 어두운 공간, 1~2색 광원, 얼굴 없는 인물, 공간 속 수치 주석, 기록 카드다. 레퍼런스의 장면·그래픽·서체·소리는 베끼지 않는다.
2. **구조: 이야기 우선.** 순서는 사건(훅 → 긴장 → 핵심 사실) → 법원의 판단 → **보상으로서의 선고**다.
   - 추측 비트는 필수가 아니다. 파일럿에서 넣은 판과 뺀 판을 비교해 정한다.
   - 선택지 띠는 없앤다.
   - 이 구조는 인용한 레퍼런스가 뒷받침하는 **가설**이다. 우리 채널에서 검증된 결과가 아니다(부록 A P13).
3. **톤: 제작자 목소리로 판결을 평가하지 않는다.** "솜방망이" 같은 말은 쓰지 않는다.
   - 구형과 선고(같은 심급·같은 피고인일 때만), 재판부의 이유를 정확히 제시한다.
   - 긴장은 순서·침묵·도식으로 만든다.
   - 핵심 사실을 오해를 낳을 만큼 늦추지 않는다.
4. **파일럿 사건: N18 훈련병 얼차려 사망 중대장.** q011(V3-05)은 관심도 확인에서 탈락했다(`research/interest/2026-10-26.md` EP11 검색 미달).
   - 사망 사건이므로 무거운 톤으로 간다. 상해 묘사와 피해자 고통 이미지는 없다. 음악 바닥은 없다(하우스 규칙).
5. **화면 비율.** 시각 체계는 9:16 Shorts와 16:9 장편(4~8분)에 함께 쓴다(§7.3, §10).
6. **렌더 경로.** 3D(@remotion/three)와 2D(SVG)를 같은 장면 하나로 스파이크하고, 오너가 실제 렌더를 보고 고른다(§11).
7. **유료 도구.** 파일럿에 꼭 필요한 유료 도구는 없다. 선택지와 비용은 §13에 있다.

- 얼굴 없는 인물만 쓴다. 머리는 이목구비 없는 마네킹형이고, 몸은 어두운 재질에 림을 준다.
- 실존 인물 사진, AI 생성 인물, 사실적인 얼굴은 쓰지 않는다.
- 근거: `PCBmzL4GpbQ`는 "AI 재연" 사실 인물로 고성과를 냈지만 신뢰·정책 위험이 있다 [관찰].
- **N18 레드라인**: 온라인에서 피고인 성별 공방이 컸다(관심도 파일 `red_line`). 그래서 성별이 읽히는 체형·머리 모양·옷을 쓰지 않고, 호칭은 "중대장", "부중대장", "훈련병"만 쓴다. 실명·이니셜·나이·계급 표기(대위·중위)는 쓰지 않는다.
- 렌더 경로 후보(§11):
  - 3D: 캡슐 마네킹, 또는 MPFB2 CC0 메시
  - 2D: 코드 실루엣 패스 + 오프셋 글로

**인용 카드 (재판부)**
- 보도 인용 그대로 쓴다.
- 핵심 구절은 화이트 볼드, 나머지는 회색.

**도식**
- 표식·괄호·화살표만 쓰고, 측정 옐로는 숫자에만 쓴다.
- 법률 용어(상상적 경합·실체적 경합)는 작은 회색 라벨로 붙인다.
- 말은 쉬운 표현("하나의 행위", "여러 개의 행위")으로 한다.

**측정 오버레이**
- 측정 옐로 점선(4px, 대시 10/8)을 12~18프레임에 걸쳐 그린 뒤, 6프레임 후 라벨을 띄운다.
- 보도 수치만 쓴다("훈련병 6명").

**역할 칩**
- 둥근 사각, 잉크 블랙 82% + 1px 회색 테두리, Pretendard SemiBold.
- 오너 레퍼런스 섬네일의 이름 칩을 바꿔서 쓴 것이다 [관찰].

**장 라벨**
- Shorts: 장면 위 작은 줄 "01 연병장 / 02 법정 / 03 선고".
- 장편: 전체 화면 장 카드 1.5초.

### 5.4 쓰지 않는 것

- L1 림 스웰: 행위 순간 빨강 림 0.6→1.0(10프레임). 사망 사건은 0.4→0.6.

### 8.3 전환
- T1 하드컷: 자막 절 경계에서. 전체 전환의 80% 이상.
- T2 매치컷: 모양을 이어 받는다. 예: 연병장 표식 → 도식 표식.
- T3 암전: 보상 직전 6프레임 페이드 후 0.6~0.8초 유지.
- T4 라이트 와이프: 편당 2회 이하. 사망 사건은 0회.
- 쓰지 않는 것: 슬라이드, 줌 블러, 글리치.

- 장편: 숏 2~5초.

## 11. 렌더 경로 스파이크 계획 (구현자용)

목적은 오너가 실제 렌더를 보고 3D와 2D 중 하나를 고르게 하는 것이다. 이 문서는 어느 쪽이 낫다고 판정하지 않는다.

### 11.1 공통 장면
N18의 S2 + S3을 합친 2.5초(75프레임)를 두 경로에서 같게 만든다.
- 연병장 가장자리에 얼굴 없는 지휘관 실루엣 뒷모습, 빨강 림
- 멀리 정렬한 6개 실루엣, 파랑 공간광
- 측정 라벨 "훈련병 6명", 역할 칩 "중대장"
- 자막 한 줄, 제목 띠, 그레인, 비네트
- 렌더 크기: 9:16 1080×1920, 그리고 같은 장면을 16:9 1920×1080으로 한 번 더(§7.3 검증)

### 11.2 경로 A — 3D (@remotion/three)
의존성 (React 18.3.1 유지 기준)
- `@remotion/three@4.0.538`
- `three@0.186.1`
- `@react-three/fiber@8.18.0`
- `@react-three/postprocessing@2.19.1`
- `postprocessing@6.39.5`
- fiber 9.x, drei 10.x, r3-postprocessing 3.x는 React 19가 필요해 쓰지 않는다.
- postprocessing 6.39.5는 three 0.168 이상 0.187 미만을 요구한다.

형상
- 지면·경계는 Plane/Box로 만든다.
- 인물은 ① 캡슐 마네킹 ② MPFB2 CC0 메시(GLB 내보내기, 성별이 드러나지 않게 체형 중립화)를 둘 다 시도한다.

재질·조명
- 어두운 MeshStandardMaterial + 프레넬 림 ShaderMaterial
- 낮은 파랑 Hemisphere + 빨강 SpotLight(뒤) + 약한 파랑 키

후처리
- Bloom
- 그라데이션 맵 듀오톤: 커스텀 Effect, 휘도 → `#05070D`/`#0B3FA0`/`#D7264F`/`#F6A6B2`
- Noise, Vignette

규칙
- 애니메이션은 `useCurrentFrame()` + `interpolate()`로만 만든다.
- `useFrame`이나 시드 없는 `Math.random`은 쓰지 않는다.
- GL은 기존 설정 `angle`을 쓴다.

### 11.3 경로 B — 2D (SVG/React)
- 의존성 추가 없음. 필요하면 `@remotion/noise`, `@remotion/paths`(MIT).
- 지면: 1점 투시 SVG 다각형.
- 인물: 코드 실루엣 패스.
- 림: 오프셋 외곽선 + `feGaussianBlur`.
- 빛: radialGradient.
- 듀오톤: `feColorMatrix` + `feComponentTransfer`(table).
- 그레인: 프레임마다 seed를 바꾼 `feTurbulence`.
- 패럴랙스: 레이어별 이동률.

- 바닥 음악은 보상 직전에 한 단계 내려간다. earshot `launch` 프리셋의 "히트 전에 음악을 내리는" 방식과 같다.

마스터
- 통합 -14 LUFS, 트루피크 -1.5 dBTP 이하(기존).
- LRA는 4~7 LU를 허용한다. v3는 1.4~1.8 LU라서 무음과 히트가 묻힌다.

### 13.5 earshot식 코드 효과음을 Remotion 타임라인에 맞추는 방법 [제안, engine-feasible]

1. **싱크의 단일 원천은 프레임이다.**
   - 장면 컴포넌트가 쓰는 이벤트 프레임을 `render.json`에 내보낸다. 예: 표식이 켜지는 프레임, 괄호가 갈라지는 프레임, 암전 시작, 보상 첫 음절.
   - 지금도 `make.py`가 큐의 `from`, `a.s1/e1`, `p.*.at`을 쓰고 있다.
   - 형식: `sfx_cues: [{frame, role, bank_id, sync: "onset"|"apex", knobs}]`. 초 = frame/30.
2. **렌더**: 오디오 단계(Python)에서 `earshot.forge.bank.render(id, …)` 또는 `earshot sfx render ID --dur --apex`로 효과음을 만든다.
   - 휘시는 `apex`(가장 큰 순간)가 컷 뒤 약 +37ms에 오게 한다.
   - 노크·클릭은 onset이 큐보다 약간 앞서게 한다(-11~-40ms, earshot `launch` 프리셋 수치).
   - 배치는 `kit.place(take, role, cue_s)`, 레벨은 `kit.gain_db(take, role, kit.bed_level(music, t))`로 한다.
3. **감사**: 렌더마다 `earshot sfx check`(클릭·잘린 꼬리·클리핑)를 돌리고, 마스터 뒤에는 `earshot measure`(LUFS·트루피크·LRA)를 돌린다. 둘 다 모델이 필요 없다.
4. **선택 검증**: `earshot timeline mix.wav --video final.mp4 --cues cues.json`으로 효과음이 그림 컷·큐 프레임에 실제로 맞는지 잰다. 모델을 내려받아야 하고 CPU에서 60~90초 영상당 약 1.5분 걸린다(README 수치).
5. **기존 `make.py sound()`와의 관계**: 지금 직접 합성하는 thunk/tick/knock/crash를 bank id로 바꾸고, 기존 더킹·loudnorm 2패스는 유지한다.
