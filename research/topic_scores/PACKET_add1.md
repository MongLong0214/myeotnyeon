# Addendum (CEO selection criteria; takes precedence). Continue.

- **Never pass a topic on summed views alone.** Each YouTube video additionally needs: days since posting, channel size (subscribers), and its performance relative to that channel's similar videos (views / that channel's median views).
  - Remove duplicate re-uploads and clips.
- **Selection conditions (all three):**
  1. **Factual:** a trustworthy original source, with the case, the trial stage and the outcome distinguishable.
  2. **Demand:** at least 2 independent kinds of demand signal, each with its source, measurement date and query (e.g. YouTube performance + search trend). Article count alone does not prove interest.
  3. **Channel fit:** the conflict reads from the first shot, and the case can be told as a sentencing question and character actions without distorting facts.
- Naver Datalab and related searches only if accessible without the key or a login; the Naver key is on hold. **Never fill an unmeasurable value with 0 or an estimate**; record it as missing.
- **Do not set an absolute pass line.** In RANKED.md, put each candidate's evidence and missing data side by side, and select relatively.
