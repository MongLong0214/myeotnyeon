## 실행하지 못한 것

- 원본 Tōdai의 1080p 재현 렌더.
- 신규 인물/세트의 실제 WebGL 프레임.
- 레퍼런스와 새 작품의 화면·동작 비교.
- 브라우저 렌더를 실제로 중단하고 재개하는 E2E 시험.
- 새 에피소드의 전편 영상·음성을 조립하는 전체 E2E.
- Kokoro 가중치 설치·영어 내레이션 합성과 발음/청취 평가.
- 사용자 PC의 GPU 성능, Windows/macOS 실행.

코드는 위 경로를 구현하지만, **구현됨과 동작 검증됨은 별개**다. 렌더 속도·하루 생산량·미적 품질 점수는 쓰지 않는다. 테스트 개수로 품질을 대신하지 않는다.

## 기존 ZIP과의 관계

이전 `animation_factory_final.zip`의 Library 항목은 조회했으나, materialize가 반환한 파일이 현재 작업 컨테이너에 존재하지 않았다. 따라서 **이전 파일을 실제로 열어 수정·회귀 검사했다고 주장하지 않는다.** v4는 사용자가 정한 조건과 기존 운영 원칙을 유지해 새로 작성한 독립 프로젝트이다. 이전 ZIP과 병합하지 않는다.

## 배포물의 범위

코드, 대본/샷 예제, 소스 고정 정보, 제작 지침, 위 검증 로그를 포함한다. 원본 렌더러·브라우저 의존성·음성 가중치는 초기 설치 때 무료 공개 원본에서 받는다. 글꼴 파일·유료 에셋·다른 사람이 만든 완성 영상을 신작 샘플로 넣지 않았다.

이 빌드에는 새 애니메이션 MP4가 없다. **이번 환경에서 화면 품질을 입증하지 못했기 때문**이며, 스토리보드를 고품질 결과물로 대체하지 않았다.

## 실제 제작 담당자가 이어서 확인할 최소 순서

1. `npm install`, `npm run setup`, 브라우저 준비 후 `npm run reference`로 원본 장면이 나오는지 확인.
2. `npm run style`의 새 실제 장면을 원본과 비교. 캐릭터/연기/배경이 못 미치면 실제 자산과 연출을 고친다.
3. 사용자가 실제 영상으로 화면풍을 결정하면 전편 확장. 판단에 부족한 부분만 detail로 출력.
4. 실제 프레임 중단·재개, 샷 하나 수정, 음성만 수정, 전편 믹스를 실행해 재사용 확인.
5. 최종 해상도 출력과 실제 청취·관람 후 납품. 아직 확인하지 않은 결과에 성공 표시하지 않는다.

설치와 코드 수정은 제작 담당자의 일이다. 사용자는 결과물 컨펌만 한다.
