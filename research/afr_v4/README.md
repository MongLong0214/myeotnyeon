# Animation Factory v4 — Reference-first

## 먼저 상태부터

**이 ZIP은 레퍼런스의 실제 렌더러를 연결하는 실행 코드와 제작 지침입니다. `레퍼런스 동급 신작 영상이 검증 완료된 완제품`은 아닙니다.**

현재 환경에서 공개 GitHub 파일을 실행용 파일로 다운로드하는 연결이 차단돼, **원본 재현 렌더와 신작 WebGL 렌더는 실행하지 못했습니다.** 같은 이유로 upstream 소스와 npm 패키지는 ZIP 안에 포함되지 않습니다. 첫 설치 때 무료 공개 소스를 받습니다. 이전 SVG 영상이나 다른 영상을 새 성공 샘플로 대신 넣지 않았습니다.

실행한 것: Node 회귀 검사, 실제 FFmpeg 이미지 시퀀스 인코딩/디코딩 fixture, 원본 보호, 변경 감지, 샷 시간 계산, 샷 함수 전체 시점의 유한값 검사, 코드 합성 효과음 출력. `VERIFY.md` 참고.

### v3와 달라진 핵심

- **최종 화면 제작 엔진 하나: Three.js + Tōdai의 실제 `anime.js`.** Blender는 필요한 모델을 만들거나 고칠 때만 쓰는 자산 도구입니다. 같은 영상을 두 엔진으로 각각 만들지 않습니다.
- upstream의 셀 명암·외곽선·배경 전용 회화 필터·광선·블룸·색보정을 가져옵니다. "블룸을 넣으면 같은 품질"이라고 바꿔 말하지 않습니다.
- 고정 커밋/파일 해시를 확인한 원작의 일부를 먼저 **벤치마크**로 재현합니다. 이것을 우리 신작이라고 표시하지 않습니다.
- 원작과 다른 인물·이야기의 실행 가능한 장면 예제를 따로 작성했습니다. **그 새 캐릭터·연기의 미적 품질은 미검증**입니다.
- 해상도를 낮춰도 실제 캐릭터·동작·재질·효과는 그대로 사용합니다. 최종 크기 정지 화면/짧은 구간으로 가는 선·눈·질감은 별도로 확인합니다.
- 임의 대본을 완성 애니메이션으로 자동 변환하는 범용 엔진은 아닙니다. 기존 코딩 에이전트가 이야기와 샷 코드를 제작하고, 사용자는 결과물 컨펌만 합니다.

## 확정 조건

영어 · 글로벌 · 얼굴 출연 없음 · 인물 중심 가능 · 9:16 · 30–45초 기본 · 가벼운 상황/반전 · 추가 유료 LLM/API/자산/음성/음악/클라우드/외주 없음. 기존 컴퓨터와 구독 범위는 사용합니다. 전기와 작업시간까지 0이라는 뜻은 아닙니다. 외부 업로드·계정 생성·결제 기능은 없습니다.

## 필요한 것

Node 20+, Git, FFmpeg/ffprobe(libx264), Chrome/Edge 또는 Playwright Chromium, WebGL2 GPU. 이 환경에서는 Node 22.16.0/FFmpeg 7.1.5/Chromium 144가 확인됐지만 실제 3D 통합 테스트는 실행되지 않았습니다. 사용자 RTX 3060 Ti에서의 시간도 아직 실측하지 않았습니다.

```sh
npm install
npm run setup
npx playwright install chromium
npm test
```

기존 Chrome을 쓰려면 `CHROME_PATH`를 지정할 수 있습니다. Linux 격리 환경에서 꼭 필요한 경우에만 `FACTORY_NO_SANDBOX=1`을 사용합니다. 일반 사용자 PC의 기본 권고가 아닙니다.

첫 설치는 인터넷이 필요합니다. 계정/API 키는 필요하지 않습니다. 최초 의존성과 선택적 음성 가중치를 받은 뒤 시각 렌더 경로는 로컬입니다. upstream 라이선스는 `vendor/todai/LICENSE`와 `vendor/todai/vendor/three/LICENSE`에 보존합니다.

## 제작 담당자가 실행할 순서 — 사용자에게 설치/모델링을 맡기지 말 것

### 1. 원본 재현: 원작이 이 환경에서 정말 나오는가?

```sh
npm run reference
```

원본 16:9 1920×1080 대표 프레임 4장과 3초 무음 구간을 `out/reference/`에 만듭니다. **제3자 원작 재현**이며 공개할 우리 에피소드가 아닙니다. 이 시점에 신작을 1080p 전편 렌더하지 않습니다.

### 2. 실제 신작 대표 샷: 새 자산에도 같은 룩이 성립하는가?

```sh
npm run style
```

`S03`의 실제 3D 6초를 360×640·24fps로 만듭니다. 벤치마크와 나란히 비교해 사용자에게 캐릭터·빛·움직임을 한 번에 판단받습니다. **동급으로 보이지 않으면 신작을 다듬습니다. 단위 검사 통과로 이 판단을 대체하지 않습니다.**

### 3. 이야기·보드·저해상도 실제 전편

`episodes/one_step_behind/SCRIPT.md`와 `episode.json`이 예제 입력입니다. 보드는 실제 장면의 주요 포즈에서 생성할 수 있습니다.

```sh
npm run boards
npm run review
npm run assemble
```

`boards`는 270×480 패널과 HTML입니다. `review`는 실제 장면의 360×640 전편 프레임입니다. `assemble`은 이것을 편집합니다. 소리가 없으면 검토 안내문에 명시합니다. **보드가 전편 렌더를 대체하지 않습니다.**

### 4. 무료 소리

```sh
npm run sound
# 선택적 로컬 TTS: Python 3.10+ 환경에 kokoro==0.9.4, soundfile, numpy, espeak-ng 설치
python tools/voice.py
npm run assemble
```

효과음/조용한 반주는 샘플 없이 코드로 합성합니다. 로컬 Kokoro 내레이션은 모델 설치와 청취가 필요하며 이번 환경에서 실행하지 않았습니다. 음성이 슬롯보다 길면 임의 가속하지 않고 막습니다. 에이전트가 문장/편집을 고칩니다. 의도하지 않은 기계음성을 자동 대체하지 않습니다.

### 5. 결정된 샷의 최종 출력

```sh
npm run final
npm run deliver
```

1080×1920 PNG를 새로 렌더합니다. 리뷰 MP4를 확대하지 않습니다. 최종 음성이 누락되면 납품 명령은 중지합니다. `LATEST.txt`가 실제 파일 위치를 가리킵니다. 해상도/디코드가 맞아도 창작 품질 승인을 자동 선언하지 않습니다.

## 바뀐 것만 실행

```sh
node tools/cli.mjs render --shot S03 --profile review
npm run assemble
```

- 제목·검토 질문: 텍스트만 갱신.
- 음성·효과음: 음원/믹스만 갱신.
- 순서 변경: 개별 샷 픽셀은 재사용하고 편집만 변경.
- S03 동작 코드: S03만 재렌더.
- 공통 캐릭터/셰이더: 그것을 쓰는 샷은 다시 렌더해야 함.
- 중단: 재실행 시 같은 작업 키의 정상 PNG만 재사용.

`detail`도 원본 장면을 새로 렌더합니다. 생성 중인 파일, 잘못된 크기의 PNG, 깨진 해시를 완료로 간주하지 않습니다. 잠금이 남으면 실제 작업이 종료됐는지 제작 담당자가 확인한 다음 그 잠금만 지웁니다. 진행 중 잠금을 자동 삭제하지 않습니다.
