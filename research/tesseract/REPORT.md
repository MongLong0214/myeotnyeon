## 정체·라이선스
- 비공개 렌더링 엔진 `tsrct`용 AI 에이전트 스킬 문서 묶음. 엔진 소스 없음. 문서 + Python 스크립트 3개(오디오 분석·효과음).
- **Mirage 독점 약관.** 사용 허용(2.2.1), 연매출 100만 달러 이상 상업 사용은 별도 계약(2.2.3), 복사·2차 저작 금지(3(e)), 리버스 엔지니어링 금지(3(m)), 경쟁 제품 금지(2.2.2). 약관은 바뀌거나 회수될 수 있음.
- → **코드·문서를 복사하지 않는다.** 아이디어만 ffmpeg 표준 기능과 일반 수학으로 직접 구현.

## 가져다 쓸 아이디어 (우선순위)
1. **2-bone IK (M):** `solveArm(어깨, 손목표, 위팔, 아래팔, 꺾임방향)` — 팔꿈치 자동, 닿지 않으면 최대 길이 고정, 팔 길이 불변 테스트. 머리 시선 맞추기. 호흡 + 제스처 + 추가 동작 합성.
2. **자막 (S–M):** `silencedetect=n=-45dB:d=0.2` 쉼 + whisper 단어 시각, 1–2줄, 조사·어미에서 끊지 않기, 50–120ms 여유, `@remotion/layout-utils` measureText로 넘침 검사.
3. **필름스트립 (S):** 컷마다 t−1f/t/t+1f + 개요 시트, 비트마다 처리 방식·샷 크기 기록해 같은 배치 3연속 금지. 보고 시 "프레임 분석"으로 표기.
4. **큐 맵 (S):** 대사 시각 → 화면 사건 → 효과음 정점 → 음악 처리. 리액션 포즈 2–4프레임 먼저 출발. 펀치라인 직전 80–200ms 음악 비움.
5. **카메라 (S–M):** 펀치인 시 두 눈 중점 화면 위치 고정, 샷 크기가 바뀌어도 눈 높이 유지.
6. **오디오 (S):** 최종 −15 LUFS / TP −1 dBTP 이하(`ebur128`, 필요 시 2패스 `loudnorm`), 덕킹 3–6dB(30–80ms / 150–350ms). TTS 원본 측정 −25.2 LUFS.
7. **효과음 (S):** `aevalsrc`로 자체 프리셋, 정점 위치 메타데이터.
8. (선택, M) 독립 비평가 2명(아트디렉터·유튜브 전략가) — 과설계 우려로 보류.
